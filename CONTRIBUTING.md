# Contributing

Thanks for helping improve this project.

## Development setup

1. Install Valheim and BepInExPack for Valheim.
2. Create the publicized Valheim assembly used by the development setup.
3. Copy `Config.Build.user.props.example` to `Config.Build.user.props` and set `VALHEIM_INSTALL`.
4. Build the solution in Visual Studio.
5. Test changes in a local world before testing multiplayer behavior.

Do not commit Valheim, Unity, BepInEx, generated binaries, or package archives. Keep changes focused and document user-visible behavior changes.
