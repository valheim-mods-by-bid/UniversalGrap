# UniversalGrasp

Hold any inventory item visually in either hand.

- **Modifier + left-click:** left hand
- **Modifier + right-click:** right hand
- Repeat the action on the same item to clear that hand.

The modifier defaults to Left Alt and is configurable locally.

Only clicks in the player inventory are intercepted. Requires BepInEx.

## Mod managers

This Thunderstore package is compatible with Gale, Thunderstore Mod Manager, and r2modman.
